# 安装c/c++编译器
- windows：
  - 可以使用 MinGW 或者 Microsoft Visual C++ (MSVC)。
    - MinGW：
      - 下载 MinGW 安装程序：MinGW 官网
      - 安装时选择 mingw32-base 和 mingw32-gcc-g++。
      - 将 MinGW 的 bin 目录添加到系统环境变量 PATH 中，例如 C:\MinGW\bin。
    - MSVC：
      - 下载并安装 Visual Studio Community 版，选择“使用 C++ 的桌面开发”工作负载。
